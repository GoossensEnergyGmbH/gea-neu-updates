# GEA – Updates

Öffentliche Ablage der Update-Ankündigung für **GEA (Goossens Energy Analyse)** der Goossens Energy GmbH.

- `update.json` – signierte Manifestdatei (Ed25519, Schema `gea-update/1`). Das Programm prüft beim Start, ob hier eine neuere Fassung angekündigt ist, und
  verwirft jede Datei, deren Signatur nicht zum im Programm eingebetteten Schlüssel passt.
- Die Installer liegen als Dateien der **Releases** dieses Repositories; die Manifestdatei nennt Adresse, Größe und Prüfsumme.

Hier liegen keine Projektdaten, keine Lizenzen und keine Zugangsdaten.
